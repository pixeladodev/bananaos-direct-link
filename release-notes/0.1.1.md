# Direct Link 0.1.1

**Direct Link** is an Apps-shelf app for BananaOS that puts two handhelds on their own Wi-Fi link so local multiplayer works **without a router**.

**Devices:** Anbernic **RG DS** and **RG DS Plus**. Made for **BananaOS 0.5.2.2**; it also works on **BananaOS 0.5.3.4**.

### What's new since 0.1.0

- **Pixel UI** in BananaOS menu style: Host, Join, Disconnect, status diagram with IPs under the link graphic, and a compact on-screen legend.
- **Guest role** label and detection when the other handheld leaves the link.
- **START menu** with **About**, **Updates**, and **Uninstall** (Y).
- **In-app updates** download and install newer releases from GitHub with checksum verification.
- **Navigation sounds** while you move between rows (same family as BananaDS LAN).
- **One-file installer:** `Install-Direct-Link.sh` goes into **`store/tiles`** once; open it from Apps and it copies the app to **`store/apps`**, adds the real tile, and deletes itself (no terminal).

### What it does

- One handheld presses **Host**, the other **Join**. The host is `10.42.0.1`; the guest takes the first free address from `10.42.0.2` to `10.42.0.9`.
- The link stays up after you leave the app, so you can start once and play several games in a row.
- Works with any shelf app that supports LAN play on this link, including **BananaDS LAN** with **Auto**.
- **Disconnect** restores normal home Wi-Fi when you had it before.

### Install or update

**Option A — one file (recommended):**

1. Download **`Install-Direct-Link.sh`** from this release.
2. Copy only that file into **`store/tiles`** on the shared **banana** folder. Do **not** replace the whole `store` tree.
3. Reboot once, open **Apps**, and run the installer tile. Then open **Direct Link** from the new tile.

**Option B — zip:**

1. Extract the zip. Copy **`direct-link`** into **`store/apps/`** and **`Direct Link.sh`** into **`store/tiles/`**.
2. Reboot once, then open **Apps > Direct Link** on both handhelds.

**`INSTALL.txt`** inside the zip has SMB and microSD steps if you need them.

### How to play

1. Open Direct Link on both handhelds. **Host** on one, **Join** on the other, until both show the link up.
2. Leave the app and open the same game on both. In BananaDS LAN, keep Local multiplayer on **Auto**.
3. When finished, open Direct Link again and press **Disconnect** on both.

### Tested on

- RG DS and RG DS Plus on BananaOS 0.5.2.2 and 0.5.3.4: host/guest, BananaDS LAN over the link, and a long session without link drops.

### Settings (optional)

`/data/banana/direct-link.conf` is read, never executed. One `KEY=value` per line: `CHANNEL` (1-11), `FREQ` (MHz), `SSID`, `BSSID`, `MAX` (seconds; `0` until Disconnect).

### Uninstall

With the link off, press **Y** in the app, then **A**. That deletes the app and its tile.

### Known limitations

- The link uses Wi-Fi channel 1 (2.4 GHz) unless you override it; crowded 2.4 GHz nearby can add lag.
- No internet while the link is up.
- The link is open (no WPA on ad hoc); it is for two friends nearby, not a private WAN.
- Only two handhelds are validated together in testing.
