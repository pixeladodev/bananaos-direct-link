# Direct Link 0.1.0

**Direct Link** is an Apps-shelf app for BananaOS that puts two handhelds on their own Wi-Fi, so games can use local multiplayer anywhere, without a router. It is the first release.

**Devices:** Anbernic **RG DS** and **RG DS Plus**. Made for **BananaOS 0.5.2.2**; it also works on BananaOS 0.5.0.1.

### What it does

- One handheld presses **Host**, the other presses **Join**. The host is `10.42.0.1`; the guest takes the first free address from `10.42.0.2` to `10.42.0.9`.
- The link stays up after you leave the app and while you change games, so you can start it once and play several games in a row.
- Works with any emulator that has LAN multiplayer: **BananaDS LAN** (Auto finds the other console by itself), **RetroArch** netplay and **PPSSPP** ad hoc.
- **Disconnect** closes the link and brings the home Wi-Fi back if it was on.
- While the link is on, Wi-Fi changes from BananaOS Settings are held back, so they can't drop a game in progress.

### Tested on

- An RG DS and an RG DS Plus on BananaOS 0.5.2.2, each as host, with BananaDS LAN and Mario Kart DS.
- A 12-minute session had no link drops (every ping between the consoles answered), and races ran at about 57-59 fps on the host.

### How to play

1. Open Direct Link on both handhelds. Press **Host** on one and **Join** on the other, and wait until both show the link as up.
2. Leave the app and open the same game on both. In BananaDS LAN, keep Local multiplayer on **Auto**; in RetroArch or PPSSPP, connect to `10.42.0.1`.
3. When you are done, open Direct Link again and press **Disconnect** on both.

### Install

1. Extract the zip. Copy **`direct-link`** into **`store/apps/`** and **`Direct Link.sh`** into **`store/tiles/`** on the shared **banana** folder. Do **not** replace the whole `store` folder.
2. Reboot once, then open **Apps > Direct Link** on both handhelds.

**`INSTALL.txt`** inside the zip has the detailed steps, including what to do if the folder ends up one level too deep.

### Settings (optional)

`/data/banana/direct-link.conf` is read, never executed. One `KEY=value` per line: `CHANNEL` (1-11), `FREQ` (MHz, wins over `CHANNEL`), `SSID`, `BSSID`, `MAX` (seconds; `0` means until Disconnect).

### Uninstall

With the link off, press **Y** in the app, then **A**. That deletes the app and its tile.

### Known limitations

- The link uses Wi-Fi channel 1 (2.4 GHz) unless you set another one; a crowded 2.4 GHz band nearby can add lag.

- There is no internet while the link is up.
- The link is open: BananaOS's wpa_supplicant has no encrypted ad hoc mode, so anyone in range could join. It is a local link, not a private network.
- Only two handhelds have been tested together.
